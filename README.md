# 炉石猎人天梯助手

面向 Windows 国服标准天梯的桌面助手，以猎人为主要使用场景，覆盖最新中文卡库、套牌管理、实时记牌、AI 建议和赛后复盘。

本地程序负责还原局面，计算工具负责核算，AI Agent 负责提出方案和解释取舍。

当前实验版已接入日志监听与回放、版本中文卡库、套牌管理、中文局面与英雄资源、记牌与概率、对局时间线、悬浮窗和无需模型的本地计算。AI 支持留牌、回合、选择、复盘和赛前套牌计划五种任务，并可承接最多四轮已有解释；用户计划、对局笔记、关键回合标记与建议归档已接入，历史查询受当时的记录时间和事件序号约束。

中文卡库页支持可收藏、全部和不可收藏牌筛选，详情按搜索时固定的 build 展示文字，可分页打开卡库提供的直接关联牌并返回。关联缺项保留未知，记录不代表完整生成池；图片只作最新浏览辅助。本地 preview25 包含大局面分批查卡、最后观察局面的精确复盘、已观察静态赠福及附魔可见性校验。

本地工具支持部分发现选择的直接后果预览、已观察“心中的恶魔”的单次亡语抽牌风险，以及结束回合与神秘恐魔的强制战斗核算。亡语预览不会杀死随从，抽牌预览不会创建实际手牌或后续动作；未确认费用、触发顺序和攻击就绪字段继续保留未知。逐牌范围见[猎人牌效覆盖](doc/hunter-rule-coverage.md)。

后续源码已支持 1–7 个神秘恐魔的联合相关分支：同一分支共享圣盾消耗、存活、生命与累计吸血，显示已开始来源的阶段见证；实际顺序与概率仍未知。本地保留完整的有限计算结果，模型对大结果只接收明确标出总数及省略情况的八条相关分支，不据此推断全局最优或斩杀。这项更新尚未加入 preview25。

后续源码还支持已观察拼装成品的“纯战吼→手牌随从 +1/+1”脚本，可衔接出牌、强化、冲锋攻击和最终主机验证，显示半段来源与逐目标模拟变化。其它组合、生成池和新实体映射仍未知，详见[拼装脚本范围](doc/assembled-script-contract.md)；此更新尚未加入 preview25。

本地 preview25 还包含对手公开手牌记忆，单独展示曾在公开场面／墓地确认、回手后同一实体仍可连续追踪的基础身份与来源，不推断当前费用、增益或牌序；历史使用当时保存的记录。输入缺口会使旧证据失效，之后新公开的可靠事实仍可重新追踪；旧错误记录只在派生视图中省略，不改原始保存内容。

preview25 新增 build 255790 的限定手牌历史展示：真实同一实体的 SHOW 与完整 HISTORY_TARGET 在可靠公开来源、相关结算块闭合及任务结算后，才进入独立身份记忆；桌面、模型和精确历史共用此边界。裸 SHOW、REVEALED、锻造／准备标记或未知隐藏块仍不足以证明公开，真实客户端时序仍待验收。

真实国服画面对照、整套常用猎人牌效以及多屏/DPI 窗口验收仍未完成。选择范围合法不代表选择后的牌效已经模拟，随机效果和缺失信息会保留未知。

## 启动与验证

源码运行需要 Windows 与 .NET 10 SDK。脚本也识别 `.local/sdk` 中的本地 SDK；首次构建需要访问 NuGet 下载 SQLite 依赖。无需 SDK 的 Windows 自包含发行包构建和校验见[发行说明](doc/windows-release.md)。

```powershell
./scripts/build.ps1
./scripts/run.ps1
```

模型配置可放在仓库根目录的 `.env`，基础字段见 [.env.example](.env.example)，可选字段见[开发说明](doc/development.md#模型配置)。程序启动时自动读取，也可在“AI 教练”页重新加载、检查连接或用 Windows 当前用户加密保存。模型与预算设置可调整工具开关、JSON 输出模式、工具轮数、输出上限、超时和单局预算；重新加载时，`.env` 显式填写的调优字段优先于界面保存值。工具禁用时不发送工具字段；可选 JSON 对象和 JSON Schema 模式需服务支持，失败不自动回退。上述更新已包含在本地 preview25 双模式包中，验收及构建方式见[发行说明](doc/windows-release.md)；包未上传发行站点。

用户提供的“野兽快”已作为首用套牌内置，开始监听前可在“记录套牌”中核对。在计划与笔记入口选择已保存的套牌版本，可维护赛前计划、标记关键回合，并查看已归档建议及工具依据。

运行全部回归检查：

```powershell
./scripts/verify.ps1
```

详见[开发与使用说明](doc/development.md)。回归测试使用控制台检查程序，运行 verify.ps1 执行；dotnet test 不是这些检查的入口。
