# 炉石猎人天梯助手

面向 Windows 国服标准天梯的桌面助手，以猎人为主要使用场景，覆盖最新中文卡库、套牌管理、实时记牌、AI 建议和赛后复盘。

本地程序负责还原局面，计算工具负责核算，AI Agent 负责提出方案和解释取舍。

当前处于方案阶段，仓库已初始化，应用代码尚未创建。
