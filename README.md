# 炉石猎人天梯助手

面向 Windows 国服标准天梯的桌面助手，以猎人为主要使用场景，覆盖最新中文卡库、套牌管理、实时记牌、AI 建议和赛后复盘。

本地程序负责还原局面，计算工具负责核算，AI Agent 负责提出方案和解释取舍。

当前实验版已接入日志监听与回放、版本中文卡库、套牌管理、记牌与概率、对局时间线、悬浮窗和本地工具验证。AI 支持留牌、回合、选择、复盘和赛前套牌计划五种任务；用户计划、对局笔记、关键回合标记与建议归档已接入，历史查询受当时的记录时间和事件序号约束。

真实国服画面对照、整套常用猎人牌效以及多屏/DPI 窗口验收仍未完成。选择范围合法不代表选择后的牌效已经模拟，随机效果和缺失信息会保留未知。

## 启动与验证

需要 Windows 与 .NET 10 SDK。首次构建需要访问 NuGet 下载 SQLite 依赖。

```powershell
./scripts/build.ps1
./scripts/run.ps1
```

模型配置可放在仓库根目录的 `.env`，基础字段见 [.env.example](.env.example)，可选预算与超时字段见[开发说明](doc/development.md#模型配置)。程序启动时自动读取，也可在“AI 教练”页重新加载、检查连接或用 Windows 当前用户加密保存。模型与预算设置可调整工具轮数、输出上限、超时和单局预算；重新加载时，`.env` 显式填写的调优字段优先于界面保存值。

用户提供的“野兽快”已作为首用套牌内置，开始监听前可在“记录套牌”中核对。在计划与笔记入口选择已保存的套牌版本，可维护赛前计划、标记关键回合，并查看已归档建议及工具依据。

运行全部回归检查：

```powershell
./scripts/verify.ps1
```

详见[开发与使用说明](doc/development.md)。回归测试使用控制台检查程序，运行 verify.ps1 执行；dotnet test 不是这些检查的入口。
