更新日期：2026 年 11 月 1 日。

## 已确定的方向

| 项目 | 设计方向 |
| --- | --- |
| 客户端 | Windows 国服 |
| 模式 | 标准天梯 |
| 主要职业 | 猎人；底层卡库覆盖其他职业和关联衍生牌 |
| 使用阶段 | 赛前、赛中、赛后均包含在第一版范围 |
| 局面来源 | 以本地游戏日志为主，导入牌码提供起始套牌 |
| AI 职责 | 查询资料、调用计算工具、比较方案、解释取舍 |
| 技术栈 | C#、.NET 10、WPF、SQLite，可配置模型 API |
| 操作方式 | 玩家操作游戏，助手显示记牌、建议和复盘 |

## 实现前需要验证的条件

国服日志对动态费用、当前选择、可用动作及特殊机制的覆盖程度，由第一阶段实际对局日志确定。牌效模拟先围绕常用的 1 至 2 套猎人展开；模型服务商和具体模型通过接入评估选择。

当前已创建应用工程并实现首批日志、卡库与 Agent 基础能力。功能实现和客户端兼容性验证的状态以开发清单和使用说明为准。
