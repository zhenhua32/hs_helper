## 确认本包信息

本包的版本、源码提交和构建状态见程序旁的 `package-manifest.json`。`SHA256SUMS` 记录逐文件校验值；下载的 ZIP 可与它旁边的 `.zip.sha256` 收据核对。校验文件只能用于核对对应的包，不使用其他版本的发行记录替代。

## 启动前与升级

已有助手数据时，先退出助手，完整备份实际数据目录，再使用新程序。默认目录是 `%LOCALAPPDATA%\HsHelper`，与程序目录分开，存放卡库、套牌、历史、加密模型配置和缓存。升级时替换程序目录，保留数据目录；不要把个人数据随程序包分享。

旧卡库会升级到格式 4（schema 4），历史库会升级到格式 3（schema 3），保留原有数据。不支持相应格式的旧程序不能直接读取升级后的库；需要回退到这类旧程序时，恢复升级前的数据目录备份。旧历史事件若缺少同序号内的状态归属，回看会省略并提示，不猜测归属。

把压缩包**完整解压到一个新目录**，保留所有 DLL 和 `samples` 目录，再双击 `HsHelper.App.exe`。不要从压缩包预览窗口启动。

日常启动无需参数。若要换数据位置，可从程序目录运行：

```powershell
.\HsHelper.App.exe --data-dir "D:\HsHelperData"
```

也可设置环境变量 `HSHELPER_DATA_DIR`；同时设置时，`--data-dir` 优先。备份和回退都应使用你实际指定的目录。

## 第一次使用

1. **核对套牌。** 首次使用空数据目录时，助手会自动保存并选中“野兽快”，可直接在“对局与日志”的“记录套牌”中核对。示例牌码也保存在随包的 `samples\decks\beast-hunter.txt`。需要使用其他套牌时，在“套牌”页粘贴实际牌码，点击“解析牌码”，命名后“保存到套牌库”。示例不代表当前构筑已全部合法；核对卡库后，再保存用于实际记录的套牌版本。

2. **准备日志。** 在“对局与日志”页填写炉石安装目录、日志目录或 `Power.log` 路径，可用“自动诊断”检查。点击“日志配置预览”，核对目标路径和内容；需要启用时点击“备份并启用日志”。配置更改要在**你自行重启炉石后**才生效，助手不会关闭或操作游戏。需要还原时可在同一窗口使用“恢复上次原配置”。

3. **核对版本并开始记录。** 在“中文卡库”页使用“同步客户端版本卡库”，获取已观察到的客户端版本号（build）对应卡库；包内不含完整卡库。若提示尚未确认版本，先诊断或连接日志，不猜测版本号，也不要用“同步最新卡库”代替本局核对。核对后保存实际套牌版本，在“对局与日志”的“记录套牌”中选中它，再“开始监听”。“我方视角”证据不足时应先核对，未知信息不会自动补齐；结束记录可点“停止”。

4. **按需使用 AI。** 在“AI 教练”页填写完整模型接口地址、模型名称和自己的 API 密钥，点击“加密保存配置”；“检查连接”由你主动执行。没有模型配置也可使用已有的记牌、历史和本地计算。密钥加密配置只供当前 Windows 用户使用，换用户或电脑请重新配置。不要分享 `.env`、密钥、个人数据库或真实日志。请求分析会把过滤后的局面和相关资料发送给所配置的模型服务；助手只提供建议，不代替你操作游戏。

## 回看与结果边界

在“对局记录”中筛选、翻页，选一局及其决策点查看当时局面；“计划与笔记”中的已保存关键回合笔记可用“打开关联局面”回跳，同序号有多个版本时需明确选择。历史分析的知识截止取当时局面的录制时刻，不因后来修改笔记而向后移动。建议归档是当时或事后保存的解释，不能当作当前可执行步骤。

日期筛选按**本机首次观察/导入时间**，不是原始游戏发生时间；个人战绩使用读取时已保存的结果。胜率只以胜负为分母，平局和未完成／未知不计入，不代表当前局获胜概率。

本地计算仅覆盖已实现的规则。卡库出现 `Unknown` 表示证据不足，不能理解为全部合法；复杂牌效、未知奥秘、随机结果和缺失身份仍有限制。条件预览不是实际发生的局面，也不能据此认证完整斩杀。真实国服流程及多屏／缩放体验仍需实际对照。

## 启动排查

可从解压后的程序目录生成无窗口诊断报告，选择一个**尚不存在**的报告文件名：

```powershell
.\HsHelper.App.exe --diagnostic-output "$env:TEMP\hshelper-diagnostic-new.json"
```

该命令不会覆盖同名文件；若文件已存在，请换新名字。它不打开主窗口、不连接模型、不创建用户数据库，仅报告程序、数据路径等启动信息，不能替代真实对局或屏幕验收。
