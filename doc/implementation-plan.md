本清单执行[第一版功能与技术设计](v1-design.md)。第一版完整覆盖赛前、赛中和赛后，开发顺序先验证国服日志，再建立可回放状态，随后接入计算和 Agent，最终贯通桌面界面。

## M0 国服日志验证

- [x] 确认本机安装目录、日志会话、Power 配置和日志中的客户端 build 来源。
- [x] 为需要修改的日志配置准备预览、备份和恢复流程。
- [ ] 使用常用的 1 至 2 套猎人记录完整对局，保存套牌版本。
- [ ] 覆盖留牌、抽牌、出牌、攻击、结算、选择与对局结束。
- [ ] 验证动态费用、法力、攻击状态、公开身份和选择项的日志来源。
- [ ] 确认是否提供可使用的动作或目标信息，并记录覆盖范围。
- [ ] 对照游戏画面标注关键时刻的预期局面，整理去身份化日志样本。
- [ ] 记录缺失字段、日志重复、会话切换、重连或回溯等特殊行为。

验收条件：样本能够明确回答每个关键字段来自哪里、何时可用、何时应标记未知。未验证能力不能作为精确计算的前提。当前实测记录见[国服日志验证记录](log-compatibility.md)。

模型评估使用相同局面样本，比较规则与工具使用是否正确、建议是否有依据、响应速度和实际费用。策略优劣通过人工复盘和后续实战观察评估，单场胜负不作为建议正确性的唯一依据。

## M4 桌面交互与完整流程

界面工作可以使用样本快照提前推进，完整流程验收依赖 M3。

- [x] 完成卡库、套牌、实时对局、个人统计和复盘入口。

- [x] 历史列表与个人统计共同使用观察/导入日期及既有筛选，支持含首尾天的本地日期、固定的最近 7／30 自然日、无效输入恢复和跨页；各职业战绩展示全筛选范围样本、胜负平未知与正确胜率分母，不从当前一页推导总计。
- [x] 提供赛前套牌分析、版本化计划/笔记编辑、关键回合标记和建议归档查看入口。
- [x] 对局与套牌计划归档按每页 100 条有界浏览，支持任务精确筛选与摘要/问题字面搜索，固定窗口范围和首屏截止；保留跨页详情、旧空/未知任务及缺失来源，旧动作与验证状态只供复盘，浏览不会扩大模型最多四轮的历史边界。
